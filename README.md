# 2027 KBO 신인 드래프트 분석 & 예상 지명 시뮬레이터

2027 KBO 신인 드래프트(2026-09-21 시행)의 지명 시나리오를 시뮬레이션하고, 구단 스카우트 관점에서 지명 전략을 세워보기 위한 도구입니다.

- **전체 시뮬레이션** — 10개 구단의 지명 성향·뎁스 니즈를 반영해 11라운드 110픽을 자동 진행
- **스카우터 모드** — 원하는 구단을 맡아 직접 지명, 나머지 9개 구단은 AI가 진행
- **선수 보드 / 구단 프로파일 / 규칙·출처** 탭 제공

산출물 `KBO_2027_draft_simulator.html` 은 단일 self-contained 파일이라 브라우저로 바로 열면 됩니다.

## 파이프라인

빌드 순서가 중요합니다. 앞 단계의 산출물을 뒤 단계가 덮어씁니다.

```bash
python3 build_data.py         # ① 스카우팅 기반 선수풀 생성 (나무위키 후보군 + 언론 보도)
python3 apply_perf.py         # ② 2026 전국대회 성적 반영 → talent 재산정
python3 apply_kbsa.py         # ③ KBSA 공식 명단 대조 → 학년·포지션·피지컬 확정
python3 build_college.py      # ④ KBSA 대학부 졸업예정자 364명 편입
python3 build_teams.py        # ⑤ 구단 지명 성향/뎁스 니즈 생성
python3 build_rosters.py      # ⑥ 등록·육성 선수풀 반영 → need 보정
python3 apply_calibration.py  # ⑦ 교차검증 기반 보정 (학년 확정, 니즈 조정)
python3 apply_applicants.py   # ⑧ 참가신청자 게이트 (명단 공표 후 활성화)
python3 run_sim.py 800 2027   # 시뮬레이션 + 몬테카를로 보드 → out/
python3 compare_fm.py 2027    # fmkorea 모의드래프트 교차검증
```

HTML 재빌드는 `template.html` 의 `__DATA__` 자리에 `{players, teams, trades, rules}` JSON을 주입하면 됩니다.

## 시뮬레이션 로직

```
score = view[team][player]                                  # 구단별 스카우팅 시각: talent + N(0, var*0.35)
      + needScale*(0.35+0.09*(R-1))*(1.3-bpa) * (need-0.5)*2
      + 고졸/대졸 선호 보정
      + (risk-0.5)*var*0.6                                  # 불확실 선수 감수 성향
      + 대졸 의무 미충족 시 가산 (잔여 3R 이내부터 급증)
      + N(0, 0.6+0.30*var) * noise                          # 당일 돌발 변수
```

- 라운드가 갈수록 BPA에서 팀 니즈 중심으로 이동
- 노이즈를 `var`에 비례시켜, 평가가 확립된 상위 후보는 잘 밀리지 않고 하위 후보만 흔들림
- 같은 포지션을 뽑으면 해당 니즈를 차감해 한 포지션 몰빵을 억제

### 반영된 규칙

- Z-shape 11R × 10구단 = 110픽 (매 라운드 1→10 동일 순서)
- 대졸 의무지명 1명 (11R에 미충족 팀은 대졸만 선택 가능)
- 지명권 이관 — 삼성 3R 7번(전체 27번) → NC 행사 (삼성 10픽 / NC 12픽)
- 2023 드래프트부터 **참가신청자만** 지명 대상 (`apply_applicants.py` 게이트)

## 한계

- `talent`·`need` 수치는 공개 정보를 계량화한 **추정치**이며 구단 공식 평가가 아닙니다
- 2026 대회 성적이 반영된 선수는 37명, 나머지는 이름·학교·포지션 수준
- 봉황대기(2026-08 진행 중), 트라이아웃(2026-09-01), 참가신청자 명단(2026-08-22 마감) 미반영
- 얼리 드래프트 신청자 명단 미공개 → `COL_EARLY` 데이터 없음
- 포수 비중 과다(14% vs 모의드래프트 5%), 투수 비중 부족(40% vs 59%) 미해결
