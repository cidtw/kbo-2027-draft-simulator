# 2차 교차검증 — fmkorea 모의드래프트 11R 전체(110픽) 대조

기준일 2026-08-09 · 내 시뮬레이터 v0.5(seed 2027) vs fmkorea 국내야구 게시판 2차 신인모의드래프트

---

## 0. 먼저 — 재현성 버그를 하나 잡았습니다

11R 데이터를 넣고 같은 시드로 두 번 돌렸더니 결과가 달랐습니다. 원인은 파이썬 엔진의 후보 순회 코드입니다.

```python
cands = list(self.available)   # ← set 순회
```

파이썬 문자열 해시는 프로세스마다 랜덤화되므로 `set` 순회 순서가 실행할 때마다 바뀝니다. `score()`가 후보마다 RNG를 소비하는 구조라, 순회 순서가 바뀌면 **같은 시드라도 난수가 다른 선수에게 배정**됩니다. `sorted(self.available)`로 고정해 해결했고, 3회 연속 동일 결과를 확인했습니다.

- 영향 범위: 파이썬 엔진의 단일 시드 결과만. HTML(JS)은 `Set`이 삽입 순서를 보존해 원래 문제없음
- 몬테카를로 지표(수백 회 평균)와 무결성 검증 결과는 영향 없음
- **1차 검증에서 "단일 시드 지표가 흔들린다"고 본 변동의 상당 부분이 이 버그였습니다.** 아래 수치는 수정 후 값입니다

## 2. 새로 드러난 최대 결함 — 선수풀 커버리지 81.8%

5R까지는 98%였는데 11R 전체로는 **20명을 아예 보유하지 못했습니다.**

> 김민서, 김동환, 박지황, 문교원, 김다운, 박서준, 김도윤, 최성음, 전수완, 유진우, 강기문, 안훈민, 이준우, 조정훈, 이지효, 정현우, 이창목, 박준서, 김우경, 지승기

이 중 상당수가 **대학 4학년**(문교원·인하대, 김다운·건국대, 박서준·성균관대, 전수완·경희대, 안훈민·유원대 등)입니다. 내 풀의 대졸은 25명뿐인데, KBSA 공식 명단상 대학 4학년만 162명입니다. **대졸 커버리지가 15% 수준**입니다.

fm이 뽑은 대졸 중 내 풀에 있는 건 곽병진·김경환·김동주·조영우·이준혁·강민구·박서진·정원진 8명뿐이고, 나머지는 전부 미보유입니다.

→ **후반 라운드 재현율의 상한을 선수풀이 결정하고 있습니다.** 모델 파라미터를 아무리 손봐도 없는 선수는 뽑을 수 없습니다.

## 3. 계통 오차 — 1차 진단이 11R에서 확정됨

### ① 포수 과대평가 (확정)

| | 투수 | 포수 | 내야수 | 외야수 |
|---|---:|---:|---:|---:|
| 내 시뮬 (110픽) | 50 (45.5%) | **14 (12.7%)** | 31 (28.2%) | 15 (13.6%) |
| fmkorea (90픽 기준) | 53 (**58.9%**) | **5 (5.6%)** | 24 (26.7%) | 8 (8.9%) |

포수 비중이 **12.7% vs 5.6%로 2.3배**입니다. 개별로도 김지율 18위↔47번, 유제민, 설재민, 원지우가 모두 25픽 이상 밀렸습니다. v0.3의 등록 포수 인원 기반 need 보정(±0.035/명)이 과합니다.

동시에 **투수 비중이 45.5% vs 58.9%로 13%p 부족**합니다. 니즈 가중치가 야수로 기울어 있습니다.

나무위키 나열 순서를 선형 감쇠시킨 값이라 실제 평판과 무관합니다. 반대 방향(과대평가)은 박서진 24↔104, 강영은 25↔84, 장민제 38↔71입니다.

### ③ 대졸 비중 과다

내 시뮬 대졸 18/110(16.4%) vs fm 9/110(8.2%). 참고로 2026 실제 드래프트 대졸은 약 14%였습니다. **fm이 대졸을 과소 지명하는 쪽**이고 제 쪽이 실제에 가깝지만, 대졸 의무지명 가산점(잔여 3R부터 +18/라운드)이 다소 세서 팀당 1.8명까지 올라간 면은 있습니다.

## 4. KBSA 미등재 선수 학년 판별 — 110픽으로 확정도 상승

110픽 전체를 기준으로 다시 갈랐습니다.

**A. fm이 지명 → 협회 등록 누락(3학년 확정적)** — 12명
설재민, 김민훈, 강인규, 민주홍, 김선빈, 김건, 배종윤, 이산, 소재휘, 조희성, 박지율 등

**B. fm 110픽 전체에서 미지명 → 2학년 유력** — 7명
**전나엘(강릉고) · 서원준(충암고) · 성세람(충암고) · 신지호(충암고) · 장근우(충암고) · 서성빈(부산고) · 한승우(유신고)**

1차(5R) 때는 8명이었는데 김선빈·배종윤·소재휘가 후반 라운드에서 지명되며 A로 이동했고, 서성빈·한승우가 새로 B에 들어왔습니다.

**충암고 4명(서원준·성세람·신지호·장근우)이 전원 B**입니다. 충암고 KBSA 3학년 7명 중 김지율·장민제·배정호는 fm이 지명했는데, 미등재 4명은 110픽 어디에도 없습니다. 이는 "충암고 명단이 통째로 누락됐다"는 가설을 약화시키고, **이 4명이 실제로 2학년**이라는 쪽을 강하게 지지합니다. 서원준이 2026 황금사자기 MVP인데 110픽 전체에서 미지명이라는 사실이 결정적입니다.

전나엘도 동일합니다(황금사자기 타격상 .611, 110픽 미지명).

## 5. 팀 배분

구단별 겹침은 키움 1(하현승), 롯데 1(이산)로 사실상 0입니다. 1차와 동일한 결론 — fm은 참가자 10인의 개인 취향이 반영된 구조라 팀 배분 재현은 목표로 삼지 않습니다. 몬테카를로 확률 제시 방식을 유지합니다.

## 6. 결론 및 조치 우선순위

**모델의 상단 보드는 검증됐습니다.** 1~2R 재현율 80~100%, 몬테카를로 ρ 0.53은 독립적인 제2 의견과 유의미하게 일치하는 수준입니다.

**3R 이하의 한계는 파라미터가 아니라 데이터입니다.** 커버리지 81.8%, 대졸 커버리지 15%가 상한을 만들고 있습니다.

| 순위 | 조치 | 근거 | 비고 |
|---|---|---|---|
| **1** | **대졸 선수풀 확장** (KBSA 대학 4학년 162명 + 2년제 2학년) | 미보유 20명 중 다수가 대졸 | 참가신청 게이트와 무관하게 선행 가능 |
| **2** | B그룹 7명 제외 (학년 확인 후) | KBSA 미등재 + fm 110픽 미지명 | 확인 경로: 각 고교 야구부 |
| **3** | 포수 need 계수 ±0.035 → ±0.015, 투수 비중 상향 | 포수 2.3배 과다, 투수 13%p 부족 | |
| **4** | KBSA 피지컬 기반 talent 사전확률 (선형 감쇠 대체) | 박찬희 등 +89픽 편차 | |
| **5** | 고교 3학년 풀 확장 | 참가신청자 명단 확정(8/22) 후 | |
